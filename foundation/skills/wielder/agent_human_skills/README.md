# Agent Human Skills

This directory groups agent/operator alignment, planning, conversation, and
external-stakeholder communication doctrine. Keep technical configuration and
script mechanics in sibling specialist directories.

## Routing

- [Operator Alignment](SKILL_OPERATOR_ALIGNMENT.md): promote repeated operator
  corrections into durable docs, config, tests, glossary, or skills.
- [Concise Operator Communication](SKILL_CONCISE_OPERATOR_COMMUNICATION.md):
  short operator-facing explanations and approval asks.
- [Grill Me](SKILL_GRILL_ME.md): one-question-at-a-time plan interrogation.
- [Consulting Mode](SKILL_CONSULTING_MODE.md): provisional architecture
  discussion without implementation residue.
- [Agent Partner Communication](SKILL_AGENT_PARTNER_COMMUNICATION.md): external
  Slack, email, document comment, and review-request voice with attribution.
- [Context Initiation Alignment](SKILL_CONTEXT_INITIATION_ALIGNMENT.md):
  lightweight project orientation before task routing.
- [Context Recovery Alignment](SKILL_CONTEXT_RECOVERY_ALIGNMENT.md): recover
  lost thread context from doctrine, diffs, artifacts, and commits.
- [Antifragile Planning](SKILL_ANTIFRAGILE_PLANNING.md): convex, evidence-first
  planning for operating systems with explicit plan/execution boundaries.
