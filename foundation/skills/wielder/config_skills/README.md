# Wielder Config Skills

This directory groups Wielder configuration doctrine. Keep configuration
resolution, HOCON ownership, lifecycle placement, and ecosystem phenotype rules
here. Keep executable tests in `antifragile/tests/` and operational script
entrypoint rules in `../script_skills/`.

## Routing

- [Configuration Guidelines](SKILL_CONFIGURATION_GUIDELINES.md): central
  PyHocon resolution, strict access, overlay precedence, CLI modulation, and
  one-accessor doctrine.
- [Epigenetic Config Contracts](SKILL_EPIGENETIC_CONFIG_CONTRACTS.md): the
  Wieldering Way for versioned HOCON contracts consumed by strict typed library
  models.
- [Ecosystem Guidelines](SKILL_ECOSYSTEM_GUIDELINES.md): ecosystem families,
  thin concrete phenotype overlays, topology ownership, and bootable runtime
  completeness.
- [Lifecycle Scope Guidelines](SKILL_LIFECYCLE_SCOPE_GUIDELINES.md): project,
  ecosystem, app, context, and test ownership boundaries for durable and
  ephemeral resources.
