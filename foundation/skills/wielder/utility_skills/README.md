# Wielder Utility Skills

This directory groups reusable working aids, local environment utilities,
connector bridges, and cross-cutting capability/naming helpers. These are not
the core config, script, test, ops, architecture, or agent-human doctrine hubs,
but they support many of those workflows.

## Routing

- [Uvenv Guidelines](SKILL_UVENV_GUIDELINES.md): uv-managed project Python
  environments, interpreter binding, shell activation, and workspace isolation.
- [Zshrc Guidelines](SKILL_ZSHRC_GUIDELINES.md): shell startup templates,
  project-local uvenv precedence, prompt labels, and VSCode terminal isolation.
- [MCP Browser Bridge](SKILL_MCP_BROWSER_BRIDGE.md): WSL-hosted Codex to Windows
  Chrome/Playwright MCP bridge setup and recovery.
- [Monday MCP](SKILL_MONDAY_MCP.md): monday.com MCP registration, token
  bridging, validation, and failure recovery.
- [Notebook Guidelines](SKILL_NOTEBOOK_GUIDELINES.md): interactive notebook
  hygiene, cell layout, and execution standards.
- [Org Task Wielding](SKILL_ORG_TASK_WIELDING.md): task-management, messaging,
  documentation, diagramming, and organizational execution surfaces.
- [Task Management White Paper](TASK_MANAGEMENT_WHITE_PAPER.md): goal lineage,
  task parcelling, ownership traceability, and asynchronous coordination
  doctrine.
- [App Incorporation](SKILL_APP_INCORPORATION.md): copying, reviving, or adapting
  app/tool/model services while preserving config ownership and provenance.
- [Capability Surface Extraction](SKILL_CAPABILITY_SURFACE_EXTRACTION.md):
  deriving honest operator-facing capability surfaces from apps, models,
  services, and modules.
- [Code Scope Extraction](SKILL_CODE_SCOPE_EXTRACTION.md): deciding when stable
  project-local helpers deserve reusable Wielder SDK promotion.
- [Functional Maximization](SKILL_FUNCTIONAL_MAXIMIZATION.md): auditing tools,
  third-party models, services, and workflows for full honest scenario coverage.
- [Naming Guidelines](SKILL_NAMING_GUIDELINES.md): layered naming semantics,
  operational clarity, and review heuristics.
