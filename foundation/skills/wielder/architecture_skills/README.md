# Wielder Architecture Skills

This directory groups general architecture-discipline doctrine that is not
specific to configuration, scripting, testing, or agent/operator communication.

## Routing

- [Scope Guidelines](SKILL_SCOPE_GUIDELINES.md): domain jurisdiction, boundary
  preservation, and scope-creep control.
- [Einstein Simplicity](SKILL_EINSTEIN_SIMPLICITY.md): thin outer layers,
  boundary-local branching, responsible-layer ownership, and abstraction
  restraint.
- [Parcelling Guidelines](SKILL_PARCELLING_GUIDELINES.md): stepping-stone
  implementation parcels with independent validation gates.
- [Antifragile Evolution](SKILL_ANTIFRAGILE_EVOLUTION.md): evolving operating
  systems under live workflow pressure while promoting durable lessons into
  reusable doctrine, config, code, or validation.
